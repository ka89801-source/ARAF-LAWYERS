# أعراف للمحامين

واجهة عربية لإدارة أعمال مكتب المحاماة، مبنية بـ HTML وCSS وJavaScript دون إطار عمل. تعمل النسخة الحالية ببيانات تجريبية داخل ذاكرة الصفحة.

## البوابات والبحث

- **العمل اليومي:** الجلسات والمهام.
- **القضايا والعملاء:** القضايا والعملاء والمستندات.
- **إدارة المكتب:** الفريق والمالية والتحليلات.
- **خدمات أعراف:** جميع فئات الخدمات وتتبع الطلبات.

تظل لوحة «اليوم» متاحة مباشرة. تجمع صفحة «كل البوابات» الروابط والإضافة السريعة، وتفتح القائمة الجانبية مجموعة واحدة في كل مرة.

يفتح البحث من الشريط العلوي أو بواسطة Ctrl/Cmd K أو /. ويشمل الأقسام وخيارات العرض والخدمات والسجلات، مع تصفية النطاق، وعرض بقية النتائج، ودعم اختلافات الكتابة العربية والأرقام العربية. اختيار خدمة يفتح نموذجها؛ إرسال الطلب يبقى إجراءً مستقلًا.

## الملفات والبناء

مصدر التنقل ودليل البحث هو `navigation.js`. تبقى الشاشات في `app.js` وملفات `views-*.js`، والأيقونات والحركات المشتركة في `core.js` و`styles.css`.

بعد تعديل ملفات المصدر:

```sh
python3 build.py
python3 -m http.server 8000
```

ينشئ البناء نسختين متطابقتين: `index.html` و`araf-lawyers.html`، ويحتفظ أيضًا بمخرج `dist/index.html`. افتح `http://localhost:8000/` لمعاينة الموقع.

## الاختبارات

```sh
npm install
npm test
```

يعتمد الاختبار على LinkeDOM للتأكد من سلوك DOM: فتح البوابات، البحث، لوحة المفاتيح، تركيز النتائج، الروابط المباشرة، وتوافق الشاشات الحالية. هذه تبعية للتطوير فقط ولا تُحمّل في الموقع.

الاختبارات لا تقيس تخطيط CSS أو المظهر الفعلي؛ تشمل المعاينة البصرية المناسبة أحجام سطح المكتب واللوحي والهاتف، والقائمة المطوية، وفتح البحث وإغلاقه، والرسوم المتحركة الأصلية.
